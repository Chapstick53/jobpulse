Engineering decisions worth noting

Measured, not guessed

Built a validation harness with a hand-labeled gold set and per-category precision / recall / F1. Error-analysis-driven iteration lifted overall F1 from 67% → 74%, reaching 100% on programming-language detection.

Data quality first

Discovered ~half the raw feed was noise — non-English text, re-posts, and spam. A cleaning pass removed 44% of postings and fixed a ranking bug where "C-suite" was being counted as the C language.

Runs itself, for free

A GitHub Actions cron ingests, cleans, extracts, and commits fresh data weekly — no server, no paid API, no credit card. The dashboard redeploys on every push.

Honest scope

Extraction is currently rule-based NLP (spaCy). The measured 74% baseline is the bar a trained NER model — the next milestone — has to beat, so improvement is provable, not assumed.
